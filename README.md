# MLOps

The current active model (*Current_Linear_Reg.pkl*) is a linear regression model trained on the top two features most highly correlated with the target variable. This serves as an upgrade to the previous version (*Simple_Linear_Reg.pkl*), which relied on only a single predictive feature. By incorporating a second variable, the new model aims to capture more complex relationships within the *sampregdata.csv* dataset for improved accuracy. Both models are located in the repository's *Models* directory, allowing users to easily load and test either version.
